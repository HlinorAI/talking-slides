# CHANGELOG.md — Audio Transcriber

## 2026-10-24

### Added

- Приложение `Transcriber.app` (Swift/AppKit, /Applications): окно
  с drag&drop аудио или выбором файла, выбор форматов PDF/PPTX,
  прогресс транскрибации, кнопки открытия результата и отмена.
- Пайплайн `pipeline.py`: аудио → транскрипция (локальная faster-whisper large,
  параметры проверены на файлах «улица Джамбула 1–6») → структура слайдов → PDF + PPTX.
- `slidebuilder.py` — офлайн-разбивка транскрипта на слайды (главы по паузам
  и объёму, выбор тезисов, чистка слов-паразитов).
- `renderers.py` — рендер презентации в PDF (альбомные слайды, кириллица)
  и PPTX (16:9).
- JSON-прогресс пайплайна в stderr для GUI.

### Changed

- Выход пайплайна пишется в `results/<имя файла>/` (txt+pdf+pptx),
  старые плоские файлы `results/` не тронуты.

### Fixed

- Качество слайдов по итогам визуальной приёмки: тезисы и заголовки больше
  не обрезаются многоточием на полуслове; заголовок не дублирует первый
  тезис; мусорные заголовки (URL, короткие фразы) заменены первым
  содержательным предложением главы; хвостовые «…» из транскрипта чистятся;
  тезисы начинаются с заглавной буквы; крупнее кегль и плотнее заполнение
  слайдов; на титуле — очищенное от префиксов имя источника.

## 2026-10-26

### Added

- Оформление слайдов вместо белого фона: темы (`themes.py`) с палитрами
  (midnight, ember, forest, slate, dawn, parchment), автоматически
  подбираемая по содержанию транскрипта; фон-градиент с декором
  (`backdrop.py`, PIL) для PDF и PPTX; светлый текст, акцентные плашки,
  крупные номера слайдов, читаемые футеры.
- Выбор темы в пайплайне: `--theme auto|<имя>`; событие stage "theme" в GUI.

### Changed

- `renderers.py` полностью переведён на тематическое оформление;
  приложение пересобрано (статус «Оформление…»).
- Презентация 00_Predislovie перегенерирована в теме midnight
  (психология/харизма); визуальная приёмка — все страницы pass.

## 2026-10-26 (форматы)

### Added

- Поддержка всех форматов, декодируемых ffmpeg (через PyAV): проверка
  `probe_audio` до транскрибации с понятной ошибкой для нечитаемых файлов;
  принимаются аудиоформаты (mp3, m4a, wav, flac, ogg, opus, wma, aiff, amr,
  ape, mka, dsf и др.) и звуковые дорожки видео-контейнеров (mp4, mov, mkv,
  avi, webm...).
- CLI: `--beam N` (1 — быстрый режим, в 2–4 раза быстрее).

## 2026-10-26 (ссылки на видео)

### Added

- Режим «ссылка → презентация»: вход пайплайна теперь принимает http(s)-
  ссылку на видео (YouTube, VK и всё, что поддерживает yt-dlp): аудио-
  дорожка скачивается (m4a 192 кбит/с, кэш в results/_downloads/),
  заголовком презентации становится название видео.
- В окне приложения — поле ссылки и кнопка «Скачать и обработать»
  (Enter в поле тоже запускает); прогресс загрузки видео отдельным этапом.
- Зависимость: yt-dlp 2026.10.21 в venv.

## 2026-10-26 (язык)

### Added

- Автоопределение языка транскрибации: `--lang auto` теперь режим по
  умолчанию; определённый язык и уверенность выводятся в лог и событием
  `detected_lang` для GUI (в окне — статус «Определён язык: …»).
- Выбор языка презентации в приложении: выпадающий список «Язык»
  (Авто + ru, en, uk, kk, es, de, fr, it, pt, tr). Список ограничен
  латиницей/кириллицей — шрифт Arial покрывает их полностью (проверено
  пробой глифов: казахские ә, ғ, қ, ө, ұ, ү, і и украинские ґ, є, ї
  отрисованы); арабский и иероглифика потребовали бы другого шрифта.

### Changed

- Язык по умолчанию: раньше жёстко ru, теперь автоопределение;
  принудительный язык остался доступен (--lang ru и т.д.).

## 2026-10-26 (редизайн + иконка)

### Added

- Иконка приложения (macOS Big Sur style): сине-фиолетовый градиент темы
  «midnight» + белая звуковая волна; генерируется скриптом
  `app-sources/make_icon.py` (PIL) → iconset → icns; встроена в бандл.
- Скрипт сборки `app-sources/build_app.sh`: swiftc + иконка + plist +
  ad-hoc подпись одной командой; Info.plist перенесён в исходники
  (app-sources/Info.plist).

### Changed

- Интерфейс переведён на современный стиль macOS/iOS: вибранс-фон
  (NSVisualEffectView .windowBackground), скрытый заголовок окна
  (fullSizeContentView), скруглённая drop-зона с SF Symbol «waveform»
  и подсказкой, плоские скруглённые кнопки (акцентная синяя «Скачать
  и обработать»), переключатели PDF/PPTX в стиле iOS (NSSwitch),
  аккуратная строка Язык; перетаскивание окна за фон.

## 2026-10-26 (HTML-плеер, звук в PPTX, главы)

### Added

- HTML-плеер презентации (формат `html`): офлайн-страница + папка `media/`
  с аудиофрагментами по слайдам; тема оформления, sticky-навигация
  с таймкодами, у каждого слайда — проигрывание его фрагмента записи.
  Включается переключателем HTML в GUI.
- Аудио в PPTX: при формате `html` или флаге `--pptx-audio` в каждый
  контентный слайд встраивается его фрагмент записи — слайд проигрывает
  себя прямо в PowerPoint.
- `chapters.txt` в формате YouTube (MM:SS Название) — готовые главы для
  описания публикации записи.
- CLI-флаг `--pptx-audio`.

### Changed

- Путь к модели и директории проекта стал переносимым: переменная
  `AT_MODEL_DIR`, затем `<проект>/model`, затем `~/whisper-model`;
  приложение ищет проект рядом с бандлом или в домашней папке.

## 2026-10-27 (правки по ревью)

### Fixed

- GUI: кнопки результатов не выходили за край окна (максимум 4 кнопки,
  TXT и главы — через «Открыть папку»).
- Приложение собиралось только под x86_64 с minos 26 при заявленном
  macOS 12+: теперь universal (arm64+x86_64), deployment target 12.0.
- Главы YouTube: первая глава ровно 00:00, формат H:MM:SS после часа,
  главы короче 10 секунд не выделяются, при <3 глав файл не пишется.
- HTML-плеер: <audio> только у слайдов со фрагментом; язык документа —
  определённый при транскрибации.
- «..» в названии видео больше не даёт путь results/..; дублированный
  safe_stem объединён в util.py.
- Отмена пайплайна гасит дочерние ffmpeg (SIGTERM-обработчик).
- GUI при отсутствии venv/проекта показывает понятное сообщение вместо
  «код, отличный от 0»; финальный статус больше не обгоняет последнее
  событие пайплайна.
- install.sh: ищет модель как пайплайн (<проект>/model учится), не
  обрывается без TTY, проверяет python 3.10+, brew-установку ffmpeg
  делает только с явного согласия.

### Added

- 16 офлайн-тестов (pytest): главы, safe_stem, слайды, рендеры,
  встроенное аудио PPTX; requirements-dev.txt, pytest.ini.

### Changed

- Английские ключевые слова тем: англоязычные записи больше не всегда
  получают тему midnight.
- Подпись переключателя HTML: «включает звук и в PPTX».
